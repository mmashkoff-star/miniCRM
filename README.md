# Excel Factory

Два скрипта для Google Таблиц: клиент чтения и записи и окно, которое собирает демонстрационный отчёт.

Цифры в отчёте случайные. Внизу листа это указано отдельно.

## Что есть в проекте

| Файл | Назначение |
| --- | --- |
| `google_sheets.py` | Клиент Google Sheets API: чтение, запись, новый лист, оформление |
| `report_app.py` | Окно на Tkinter. По периоду и двум полям создаёт новый лист-отчёт |
| `.env` | ID таблицы и имя листа по умолчанию |
| `excel-factory-512714-341d64a29ff2.json` | Ключ сервисного аккаунта. В репозиторий его класть не нужно |

Отчёт пишется на новый лист. Лист из `SHEET_NAME` (сейчас `Invoices`) не изменяется.

## Подготовка

Нужен Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Сервисному аккаунту нужен доступ редактора к таблице. Почта аккаунта лежит в JSON-ключе, в поле `client_email`. Её нужно добавить в «Настройки доступа» таблицы.

В `.env`:

```env
SPREADSHEET_ID=id_из_адреса_таблицы
SHEET_NAME=Invoices
# GOOGLE_CREDENTIALS_PATH=путь_к_ключу.json
```

`SPREADSHEET_ID` — фрагмент между `/d/` и `/edit` в адресе таблицы. Если `GOOGLE_CREDENTIALS_PATH` не задан, берётся JSON-ключ из корня проекта.

## Генератор отчётов

```powershell
python report_app.py
```

В окне четыре поля:

- период с и период по, формат `ДД.ММ.ГГГГ`;
- подразделение: продажи, логистика, производство, маркетинг или финансы;
- ответственный.

Дальше скрипт сам заполняет реестр операций, суммы, сводку, заключение и блок подписи. Сумма строки считается формулой «цена × количество»: если поменять цену или количество, итог и средний чек пересчитаются. После записи можно сразу открыть таблицу.

Каждый запуск создаёт отдельный лист, например `Продажи ОТ-2026-2767`.

Проверить подключение без окна:

```powershell
python google_sheets.py
```

Скрипт печатает список листов и содержимое листа из `SHEET_NAME`.

## Клиент таблиц

```python
from google_sheets import GoogleSheetsClient

sheets = GoogleSheetsClient(
    spreadsheet_id="YOUR_SPREADSHEET_ID",
    credentials_path="excel-factory-512714-341d64a29ff2.json",
    default_sheet="Invoices",
)

sheets.read_all()
sheets.update("A1", [["Hello", "World"]])
sheets.append([["ещё", "строка"]])
sheets.create_sheet("Новый лист")
sheets.batch_requests([...])  # объединение, шрифты, границы, ширины
```

Если имя листа в диапазоне не указано, подставляется `default_sheet`: `"B2"` становится `"Invoices!B2"`.
